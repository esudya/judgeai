## Правила для краулера (черновик)
- Уважать robots.txt каждого хоста; не обходить капчу.
- Честный User-Agent с контактом проекта; ≤ 1 запрос / 2 с на хост; экспоненциальная пауза при 429/5xx.
- Кешировать сырой HTML на диск (sha256), повторно не скачивать.
- Дедупликация между источниками по УИД дела (есть в 7 из 9 приватных образцов).

## sudact.ru — детали (проверено 27.10)
- **Sitemap:** `sitemap.xml` — индекс из 2 частей: `sitemap_part_0.xml.gz`, `sitemap_part_1.xml.gz`. Имена не говорят о типе суда/дате; число URL неизвестно. Следующий шаг (на Mac): скачать обе части, посчитать URL с префиксом `/regular/doc/` и проверить, покрывает ли sitemap все дела или только часть. Если только часть — нужен второй способ перечисления (сайты судов).
- **Происхождение текстов** ([sudact.ru/about](https://sudact.ru/about/)): «использование информации только из достоверных источников – официальных сайтов судов РФ», акты включаются «в том виде, как они размещены в первоисточнике». Первоисточник тех же текстов — сайты судов; дедупликация по УИД обязательна.
- **Обезличивание:** для судов общей юрисдикции «из указанных актов исключаются персональные данные» кроме фамилий и инициалов участников.
- **Правила использования:** пользовательского соглашения на сайте не найдено (в подвале только «О проекте», «Политика в отношении обработки ПД» и «Все права защищены © 2012-2026»). Про API, массовую выгрузку и автоматический доступ сайт ничего не говорит.

## Юридические заметки (проверить юристом)
- Тексты судебных решений — официальные документы и не являются объектами авторского права (пп. 1 п. 6 ст. 1259 ГК РФ) — по памяти, сверить с текстом ГК.
- Но сайт-агрегатор может иметь право изготовителя базы данных (ст. 1333–1334 ГК РФ): извлечение «существенной части» базы без разрешения может быть нарушением. Поэтому: брать умеренный объём, написать проекту с просьбой разрешения/выгрузки (конкурс ВС — хороший аргумент), для больших объёмов — первоисточники (сайты судов).
- Даже обезличенные тексты содержат фамилии — хранение = обработка ПДн (152-ФЗ). В precedent_case — только структурированные признаки и обезличенная фабула; сырые HTML — с ограниченным доступом.

## Вывод на сейчас
Для демо (300–500 приговоров по 2–3 статьям) — sudact.ru через sitemap: robots разрешает, запрета в правилах не найдено. Для большой базы — первоисточники (сайты судов) и/или договорённость с sudact. Решение о масштабе сбора — за пользователем.
